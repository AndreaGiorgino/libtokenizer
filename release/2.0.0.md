# libtokenizer v2.0.0

Tokenizer library in Cpp23

> [!IMPORTANT]
> Since this library is still in development, it may not work correctly or some
> functionalities might be missing

## What's new

- `BREAKING`: Complete ABI implementation update
- Improved testing framework

## Build

### Requirements

- [CMake](https://cmake.org/)

### Compilation

```bash
git clone https://github.com/AndreaGiorgino/libtokenizer
cd libtokenizer

./build.sh
```

Build targets:

- `build`
- `debug`
- `test`
- `example`

> Run `./build.sh --help` for the build script usage

## ABI quick reference

### `Tokenizer`

Definitions:

- `TokenType`: Represents the token types

  | Name                  | Brief                            | Affected by options                                |
  | :-------------------- | :------------------------------- | :------------------------------------------------- |
  | `None`                | Initial state                    | `-`                                                |
  | `Eof`                 | End of stream                    | `-`                                                |
  | `NewLine`             | New line                         | `CollapseSpaces`, `IgnoreSpaces`                   |
  | `Space`               | Space                            | `CollapseSpaces`, `IgnoreSpaces`                   |
  | `Identifier`          | Identifier                       | `AllowDashIdentifier`, `AllowUnderscoreIdentifier` |
  | `NumericFloat`        | Numeric float                    | `AllowUnderscoreNumeric`                           |
  | `NumericInt`          | Numeric int                      | `AllowUnderscoreNumeric`                           |
  | `Symbol`              | Symbol                           | `-`                                                |
  | `StringBacktickQuote` | String quoted with backticks     | `CollapseStrings`                                  |
  | `StringDoubleQuote`   | String quoted with single quotes | `CollapseStrings`                                  |
  | `StringSingleQuote`   | String quoted with double quotes | `CollapseStrings`                                  |

- `Token`: Represents a token
- `Options`: Represents the tokenizer options

  | Name                        | Brief                                                      |
  | :-------------------------- | :--------------------------------------------------------- |
  | `AllowDashIdentifier`       | Allow dashes to be part of identifiers                     |
  | `AllowUnderscoreIdentifier` | Allow underscores to be part of identifiers                |
  | `AllowUnderscoreNumeric`    | Allow underscores to be part of numeric tokens             |
  | `CollapseSpaces`            | Treat multiple matching spaces as one token                |
  | `CollapseStrings`           | Treat quotation marks as the start of a TokenType::String* |
  | `IgnoreSpaces`              | Do not return TokenType::NewLine and TokenType::Space      |

- `OptionsSet`: Represents the bitset containing the options

Methods:

- Modifiers:
  | Name    | Brief                                    |
  | :------ | :--------------------------------------- |
  | `get`   | Get the next token                       |
  | `peek`  | Peek the next token                      |
  | `tellg` | Get the stream reading position          |
  | `seekg` | Set the stream reading position          |
  | `eof`   | Check whether the stream has reached EOF |
